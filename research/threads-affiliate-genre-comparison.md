## 2. ジャンル別の詳細

### 2-1. 自己啓発

| 観点 | 内容 |
|---|---|
| 悩んでいる人 | 20〜40代の会社員、転職を考えている人、副業を始めたい人、習慣化や自己肯定感に悩む人。Threadsの中心層と重なりやすい |
| 悩みの強さ | **中程度**。「なんとかしたい」気持ちはあるが、今日すぐお金を払うほど切迫しているとは限らない（ここはリサーチに基づく推論） |
| ネタの作りやすさ | **◎**。本の要約・名言・習慣術・仕事術・体験談など、ネタは実質的に尽きない。ただし**競合がとても多く、差別化が難しい** |
| 紹介できる商品・サービス | ・Audible（Amazonアソシエイト経由。無料体験の登録で報酬が出るとする解説記事多数）<br>・audiobook.jp（A8.netで提携可。ビジネス書が充実）<br>・書籍（Amazon・楽天）<br>・オンラインスクール、転職・キャリア系サービス（もしもアフィリエイト・afbなどで取り扱いがあると確認） |
| 収益化のしやすさ | **○**。オーディオブックの無料体験は成約のハードルが低い。書籍は単価が低い。高単価は転職・スクール系だが、自己啓発の「隣の」ジャンルになる |
| リスク | 「年収○倍」のような誇大表現は景品表示法のリスクになる。競合が多く、埋もれやすい |

### 2-2. 占い

| 観点 | 内容 |
|---|---|
| 悩んでいる人 | **30〜50代の女性が中心**。矢野経済研究所の調査（2024年発表）では女性顧客が約90%、30〜50代が約80%、利用目的の約85%が「恋愛・男女関係」とされる |
| 悩みの強さ | **高い**。復縁・片思い・不倫・結婚など、「人に相談しにくい」「今すぐ答えがほしい」悩みが中心 |
| ネタの作りやすさ | **◎**。星座・誕生日・タロット・数秘術、今日の運勢、季節のイベントなど、決まった型で毎日投稿しやすい。「当てはまる人はいいね」形式で反応も取りやすい |
| 紹介できる商品・サービス | ・電話占い／チャット占い（例：エキサイト電話占い、電話占い絆など。複数ASPで提携可能と確認）<br>・占いアプリ、メール占い<br>・A8.net・afb・アクセストレード・もしもアフィリエイト・バリューコマース・レントラックスなどが占い案件を扱っているとされる |
| 収益化のしやすさ | **◎**。新規会員登録や初回利用が成果条件の案件が多く、単価が高めの案件もある（例：afbで1件8,000円を超える案件があるとする記事あり。**実際の単価はASPで確認が必要**） |
| 市場 | 占いサービス市場は2023年度で**997億円**（矢野経済研究所）。電話占い・チャット占いなどは成長傾向 |
| リスク | 「必ず復縁できる」「当たる」と断定する表現はNG。不安をあおる投稿はMetaの規約と景品表示法の両方に抵触するおそれがある。競合も多い |

### 2-3. スピリチュアル

| 観点 | 内容 |
|---|---|
| 悩んでいる人 | 占いと重なる女性層に加えて、「生きづらさ」「人間関係」「運気」「自分の使命」に悩む人。悩みの対象は恋愛に限らず幅広い |
| 悩みの強さ | **人によって大きく違う**。深刻な悩みを持つ人もいれば、癒やしや趣味として楽しむライト層もいる |
| ネタの作りやすさ | **○**。エンジェルナンバー、引き寄せ、浄化、新月・満月などネタはあるが、抽象的になりやすく、他と差がつきにくい |
| 紹介できる商品・サービス | ・電話占い／霊視系の鑑定サービス（占い案件とほぼ同じ）<br>・パワーストーン・開運グッズ（物販）<br>・関連書籍<br>・A8.netには「スピリチュアル」関連の案件があるとの情報あり（案件ごとの詳細は未確認） |
| 収益化のしやすさ | **△〜○**。スピリチュアル単体の高単価案件は、占い案件と比べて確認しづらい。物販は単価が低い。結局は電話占い案件に流れる構造になりやすい |
| 市場 | 矢野経済研究所の推計では「スピリチュアル関連ビジネス市場」は約4.2兆円（2023年度）。ただしこれは**非常に広い定義**（健康・癒やし系なども含むとみられる）であり、アフィリエイトで狙える市場の大きさとは別物 |
| リスク | **3ジャンルで最も高い**。霊感商法は消費者契約法の改正で取消しの対象になっている。「持つだけで金運が上がる」といった効果をうたう表現は、景品表示法・薬機法（健康効果に触れる場合）のリスクがある。アカウントの信用を失いやすい |

## 4. 結論：取り組みやすい候補

### 第1候補：**占い**（ただし「恋愛占い」に絞り込む）
**理由**
1. **悩みの強さと、成果までの距離が最も近い。** 恋愛の悩みは「今すぐ相談したい」という緊急性があり、電話占い・チャット占いの初回利用という「すぐ行動できる出口」が用意されている。
2. **ネタを型で量産できる。** 星座×今週の恋愛運、誕生月の診断など、毎日投稿を続けやすい。
3. **Threadsの女性ユーザーと相性がよい**うえに、市場は約1,000億円規模で成長傾向にある（矢野経済研究所）。

**見落としやすい欠点（反対側からの検討）**
- 競合が多く、「今日の運勢」だけのアカウントは埋もれる → **「30代・復縁」「社内恋愛」のように、誰に向けたアカウントかを絞る**ことで差をつける。
- 占い師本人ではないアフィリエイターは信頼を得にくい → 「占いの結果を出す」よりも「**自分で電話占いを使ってみた体験・選び方・注意点**」を語る立場のほうが信用されやすく、規約上も安全。
- 不安をあおると一時的には伸びても、アカウントとASP提携の両方を失うリスクがある。

### 第2候補：**自己啓発**（オーディオブックを入口にする）
- ネタが尽きず、リスクも低いので**アカウントを長く育てる基盤**に向いている。ただし単価と緊急性が低く、競合が非常に多いため、**短期で収益を出すには不利**。
- 「転職・副業」寄りにずらすと単価が上がるが、それは実質的に別ジャンル（キャリア系）への転換になる。

### 推奨しない（単独では）：**スピリチュアル**
- 法的リスクと信用リスクが最も高く、稼げる出口も結局は占い案件と重なる。**占いアカウントの中の「ネタの一部」（新月・満月など）として使う**のが現実的。

## 5. すぐ実践できるアクションプラン

| 期間 | やること | 判断基準 |
|---|---|---|
| 1日目〜3日目 | A8.net・afb・もしもアフィリエイトに登録し、電話占い・チャット占いの案件を**3〜5件**、実際の単価・成果条件・SNSでの掲載可否で比較する | 「SNSでの掲載可」「新規登録で成果」の案件があるか |
| 1週目 | ターゲットを1行で決める（例：「復縁したい30代女性」）。競合アカウントを10個分析し、伸びている投稿の型を集める | 同じ型の投稿がすでにあふれていないか |
| 2〜5週目 | リンクは貼らず、1日2〜3投稿で**フォロワーと反応の型づくり**に集中する（占い7：体験談・選び方3） | 保存・返信が多い投稿の型を特定する |
| 5週目以降 | 自分で案件を使った体験を投稿し、#PRを明記してリンクで誘導する。プロフィールのリンクも活用する | クリック率と成約件数 |
| 並行して | 自己啓発（Audible・audiobook.jp）はサブのネタとして試し、反応を比べる | 3か月後に2ジャンルの成果を比較し、力を入れるほうを決める |

**やってはいけないこと（全ジャンル共通）**
- 「必ず当たる」「絶対に復縁できる」「人生が変わる」といった断定表現
- 不安をあおる投稿（「このままだと不幸になる」など）
- 広告表記（#PR）なしのアフィリエイトリンク
