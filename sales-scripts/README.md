構成はどれも同じです：受付突破 → キーマン接続後 → 他社利用中への切り返し → ヒアリング → クロージング → 引き継ぎシート → KPI

---

## 設計の考え方（見落としやすい点と、その対策）

| 見落としやすい点 | なぜ問題か | スクリプトでの対策 |
|---|---|---|
| 乾メソッドは個人向け・訪問販売の出身 | 3度押しや即決を法人の高単価商材でそのまま使うと、委託元のブランドを傷つけ、キャンセルや商談不成立が増える | 「押す」相手を〈アポ〉から〈相手の課題をはっきりさせること〉に移した。3回押してだめなら引くルール、アポにしない基準（各4-5）を入れた |
| アポの「数」と「成約」は別物 | 委託報酬がアポ単価なら短期的には得でも、成果報酬（商談化・成約）では質の低いアポは赤字になる。委託の継続にも響く | BANTの確認、決裁者の同席、商談前の宿題、引き継ぎシートで、成約しやすいアポだけを渡す |
| 本当の競合は「他社」ではなく「何もしない」 | 燈ならChatGPTで十分、erなら今のままで回っている、という現状維持の気持ちが一番の壁 | 相手が言った数字を年額に直す（各4-3／4-4）。erは2027年4月の制度切り替えを期限として使う |
| 名乗り・実績の数字・費用の答え方 | 委託元の許可がない言い方は、契約違反やクレームになる | 各スクリプトの0-1に「委託元と合意すること」をまとめた。※確認の印がある所は、架電前に必ず確認する |
| 人材紹介の法令 | 「人件費が安くなる」「絶対辞めない」は誤解を招き、法令上もリスクがある | erスクリプトの0-4にNG表現をまとめた |
| 動画は視聴していない | 言い回しの細かいニュアンスは、検索結果と記事からの再構成 | ◎の動画を優先して視聴し、自分の言葉で書き直す |

## すぐ動くためのアクションプラン（2週間）

| 時期 | やること | 完了の基準 |
|---|---|---|
| 1日目 | 燈・erそれぞれと、0-1の表（名乗り、アポの定義、使ってよい数字、費用の答え方、NG表現）を合意する | 合意内容をスクリプトの※確認の所に書き込み終わる |
| 1〜2日目 | 00の「優先7本」を視聴（合計2時間程度）。スクリプトの言い回しを自分の口調に直す | 声に出して読んで、つかえる所がない |
| 2日目 | ロープレ：受付の5パターン（1-1〜1-5）×10回、他社利用中の上位3パターン×10回 | スクリプトを見ないで言える |
| 3〜7日目 | 燈は建設・製造を各100件、erは建設を150件架電。全件をKPIの表に記録 | 合計350件の基準値（接続率・アポ率・断り理由TOP3）が出る |
| 8日目 | 振り返り：断り理由TOP3へのトークを追加、効かなかった言い回しを削除 | スクリプトv1.1に更新 |
| 9〜13日目 | v1.1で架電。委託元から商談の結果（商談化・成約）のフィードバックをもらう | アポ1件ごとの温度感（A/B/C）と結果の対応がわかる |
| 14日目 | 成約したアポに共通するヒアリングの答えを抜き出し、4-5（アポにしない基準）を見直す | スクリプトv1.2と、委託元への報告（アポ数・質・改善点）を提出 |
